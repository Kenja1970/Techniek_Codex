# UX/UI Standards

## Product Direction

Techniek TwinSim Studio should feel like a technical control-room tool that plant managers, engineering managers, and executives can understand without losing credibility with engineers.

Design principles:

- Dark navy control-room base with teal/cyan operational signals and amber/rose/violet status accents.
- Dense but readable layouts for repeated use.
- No marketing-style landing experience inside the working app.
- Manager-facing copy should explain operational meaning without hiding technical assumptions.
- Canvas interactions should remain optional for experienced users and discoverable for new users.

## Accessibility And Responsiveness

Use WCAG-aligned practices:

- Maintain strong text contrast.
- Preserve visible focus states through browser defaults or explicit states.
- Keep controls keyboard reachable.
- Avoid text overlap at mobile, tablet, and desktop widths.
- Make charts useful alongside nearby metric summaries.

Review against Nielsen Norman usability heuristics:

- Visibility of system status.
- Match between system and real-world language.
- User control and freedom.
- Consistency and standards.
- Error prevention.
- Recognition rather than recall.
- Flexibility and efficiency of use.
- Aesthetic and minimalist design.
- Help users recognize, diagnose, and recover from problems.
- Help and documentation.

## Nightly UX Review

Each refinement pass should review:

- Studio object placement and connector clarity.
- Dashboard hierarchy and scanability.
- Executive interpretation language.
- Mobile/tablet behavior.
- Keyboard shortcut safety.
- Import/export feedback.
- Figma-aligned design tokens and component inventory.

# Figma Design Brief

## Direction

Techniek TwinSim Studio should feel like a dark blue/teal digital-twin control room: technical, calm, manager-readable, and executive-presentable.

## Core Surfaces

- Home: product identity, local-first DES concept, baseline preview.
- Demo Lab: preset scenario library and quick-run metrics.
- Studio: smart object library, simulation canvas, properties, controls, bottleneck analysis, inventory, and timeline.
- Executive View: baseline interpretation, throughput, bottleneck, WIP, inventory impact, rework/scrap impact, and future scenario comparison.

## Component Targets

- Smart object icons for manufacturing, logistics, and engineering work.
- Routed connector styles for production, material, rework, scrap, and information/control.
- Dashboard cards with restrained status color.
- Inventory panel with reorder point visibility.
- Bottleneck suggestion panel with plain-English operational reasoning.
- Timeline/Gantt view for where time is lost.

## Responsiveness

Design should cover:

- Desktop control room layout.
- Tablet layout with stacked panels.
- Mobile read-only/scanning layout, with Studio remaining usable but not over-optimized at v1.

## Figma Workflow

Figma is a refinement tool, not a runtime dependency. Future Figma Pro workflow can refine layout system, tokens, smart object icons, dashboard hierarchy, Studio usability, and executive clarity when the local Figma/Codex connection is available.

# Smoke Test

Run:

```bash
npm run smoke
```

Expected:

- Simple Production Line loads.
- The simulation creates tokens.
- Station metrics are produced.
- Timeline output exists.
- A bottleneck is identified.

Manual browser smoke:

- `npm run dev`
- Open the local Vite URL.
- Navigate Home, Start Here, Demo Lab, Studio, Executive View, Use Cases, and About.
- Run a scenario from Demo Lab.
- Open a scenario in Studio.
- Drag a smart object onto the canvas.
- Select and edit an object.
- Create a connector.
- Export scenario JSON.
- Export results JSON/CSV.

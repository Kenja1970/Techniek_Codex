# UX Checklist

Review before committing UI changes:

- Navigation works on desktop and mobile.
- Studio controls remain readable and do not overlap.
- Canvas objects can be selected, moved, connected, duplicated, and deleted.
- Property edits are visible after selection changes.
- Import/export controls give usable artifacts.
- Keyboard shortcuts do not fire while typing in inputs.
- Charts have nearby KPI summaries.
- Bottleneck suggestions are plain English and do not mutate the baseline.
- Dark control-room aesthetic remains consistent without relying only on one hue.
- Text contrast is acceptable for manager-facing demos.
